# Simple Flask app

Jalankan per-baris:

```ps1
python -m ensurepip
python -m pip install -r requirements.txt
```

Lalu jalankan (satu saja):

```ps1
# (pilih satu) untuk powershell:
.venv/bin/activate.ps1

# (pilih satu) untuk cmd:
.venv/bin/activate.bat

# lalu jalankan ini terakhir
flask --app src/main.py run
```
